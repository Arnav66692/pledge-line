The After-Hours Line For Donors And Subscribers

Pledge Line. Your Gift, Right From PayPal

A monthly donor calls after hours to check, pause or restart a gift. The line reads PayPal first, changes nothing until a separate yes, then reads PayPal back.

Every sentence it says sits next to the PayPal read behind it. It runs on PayPal's test system, so no real money moves.

          Questions

          • Only which request you made, from a fixed list: check, pause, restart, cancel, a one-time gift, or a question. Code checks the PIN, asks for your yes, calls PayPal and reads the result back.

          • Nothing changes until you say yes in a separate turn. The line reads PayPal before the change and after it. If PayPal refuses, or the result can't be confirmed, it says so and doesn't claim success.

          • Every sentence the line said, each beside the PayPal read that backs it. The file is signed, so it's tamper-evident. Change one letter and the check page names the sentence that changed.

          • The PayPal calls are real, on PayPal's sandbox, so no real money moves. The gift belongs to a test account, and every visitor shares it. No nonprofit uses the line yet.

          • Small nonprofits with monthly donors, and any business with PayPal subscriptions. The subscribers page shows how.
