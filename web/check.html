Is this the receipt the line gave?

Choose a receipt file from the line, or drop it here. The line checks it against its own key and says whether anyone changed it, and which sentence. It reads the file to check it and keeps nothing.

A check here can only say the file matches what this line signed. To check a file without this server, save the line's public key from /receipt-key as receipt-key.json and run node scripts/check-receipt.js your-file.json --key receipt-key.json from the Pledge Line code.
